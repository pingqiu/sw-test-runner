## Changed Behaviour

- R1: the decoder has an independent HardDeadline lifetime, not the enrollment
  work context. Buffered replies are drained before channel EOF is reported;
  there is no competing closed-error channel that can discard a final reply.
- R2: the custodian's last-resort timer is HardDeadline. WorkDeadline still
  refuses new authorization. Controller EOF remains an independent cleanup
  trigger, and the controller may settle during its reserved cleanup window.
- R3: calls reject an already-cancelled context before encoding. A failed or
  cancelled write poisons the channel and closes its pipe. A cancelled encoder
  is joined while the per-channel gate is held; the channel is never reused.
  A fully transmitted request can already have executed when a reply is lost:
  that outcome is UNKNOWN, not a no-execution or absence guarantee.

R3's join relies on the transport Close unblocking Write. Local pipe and fake
backend controls cover that case. A blackholed shared SSH transport has not
been qualified; ssh channel Close only sends a close message, so peer/connection
progress can still matter. Do not claim a proven real-SSH deadline bound from
the fake. This needs the R6 connection-custody decision below, not a unilateral
close of the node's shared client that disrupts other jobs.

## Controls

The same tests distinguish the old source before production edits and the
correction afterwards:

- Real SSHJobs/OpenCommand over local Git Bash with a Go stand-in custodian:
  thirty Scope.Close calls must retain settlement replies after work-context
  cancellation. The fixture executes no workload and owns no network endpoint.
- A blocked writer must be closed and joined before its cancelled call returns;
  a second call must not send another byte on the poisoned channel.
- Local WSL Linux: a fresh real custodian authorizes an empty test process,
  remains reachable after WorkDeadline, and returns a settled receipt before
  HardDeadline. The fixture owns/reaps its child; this is not SSH or RDMA/lab.

The original 61 Scope/argv tests are regressions, not proof of the open R4-R6
items. Broader native descendant/escaping-session and real-SSH tests remain
unqualified. Test fixtures have no production entrypoint outside Go tests.

## Pack Contract: R7 And R8

R7: Wait and Kill are work-phase calls. They are cancelled once the scope work
context ends. Packs requiring a native exit-code verdict must Wait before
WorkDeadline, leaving their own collection margin. Always/cleanup may Stop for
absence proof, but Stop does not manufacture an exit receipt or success code.

R8: KillWitness describes only the exact leader generation and the accepted
leader signal. It proves neither descendant termination, DMA completion nor
source reclamation. Wait/Stop must still prove complete custody settlement.
